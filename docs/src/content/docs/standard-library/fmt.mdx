---

## String Formatting

You can format strings using positional or named arguments via `fmt.format`.

```flame
import std.fmt

// Positional formatting
let greeting = fmt.format("Hello, {0}! Welcome to {1}.", ["Alice", "Flame"])
println(greeting) // "Hello, Alice! Welcome to Flame."

// Named formatting (using an object/formula)
let welcome = fmt.format("Welcome, {name}! Your role is {role}.", { name: "Bob", role: "Admin" })
println(welcome) // "Welcome, Bob! Your role is Admin."
```

| Method | Arguments | Returns | Description |
| :--- | :--- | :--- | :--- |
